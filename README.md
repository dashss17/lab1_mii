## Описание

Реализация метода вращений Якоби для нахождения собственных чисел и собственных векторов действительной симметричной матрицы. 

Метод основан на последовательных ортогональных вращениях, которые обнуляют максимальный недиагональный элемент матрицы. Исходная матрица постепенно приводится к диагональному виду, её диагональ даёт собственные числа, а накопленная матрица вращений становится матрицей собственных векторов. 

Работа оформлена в виде устанавливаемого Python-пакета `jacobi_package` и покрыта тестами `pytest`.

## Возможности

- Проверка входных данных: матрица должна быть квадратной и симметричной.
- Поиск максимального по модулю недиагонального элемента.
- Итерационное обнуление недиагональных элементов вращениями.
- Накопление матрицы собственных векторов.
- Настраиваемая точность (`eps`) и лимит итераций (`max_iter`).
- Информативные исключения (`ValueError`, `RuntimeError`) при некорректных входных данных или отсутствии сходимости.

## Использование

Пример вызова функции:

```python
import numpy as np
from jacobi_package import jacobi_eigen

A = np.array([[2.0, 1.0],
              [1.0, 2.0]])

vals, vecs = jacobi_eigen(A)

print("Собственные числа:", vals)        # [1. 3.]
print("Собственные векторы:\n", vecs)

# Проверка: A @ v == lambda * v
for i in range(len(vals)):
    v = vecs[:, i]
    lam = vals[i]
    assert np.allclose(A @ v, lam * v)
```

### Параметры функции

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `A` | `np.ndarray` | — | Квадратная симметричная матрица n × n |
| `eps` | `float` | `1e-9` | Порог для суммы квадратов недиагональных элементов |
| `max_iter` | `int` | `10000` | Максимальное число итераций |

### Возвращает

- `eigenvalues : np.ndarray` — одномерный массив собственных чисел;
- `eigenvectors : np.ndarray` — матрица, столбцы которой являются собственными векторами.

### Исключения

- `ValueError` — матрица не квадратная или не симметричная;
- `RuntimeError` — алгоритм не сошёлся за `max_iter` итераций.

## Алгоритм (кратко)

1. Проверяем, что матрица квадратная и симметричная.
2. Инициализируем V = E (единичная матрица) и A_curr = A.
3. Считаем сумму квадратов недиагональных элементов S.
4. Пока S > eps:
   - Находим максимальный по модулю недиагональный элемент A[p, q].
   - Вычисляем C = (Aqq − App) / (2 · Apq).
   - Считаем t = sign(C) / (|C| + √(C² + 1)) (при C = 0 берём t = 1).
   - c = 1 / √(1 + t²), s = t · c.
   - Обновляем диагональ: App ← App − t · Apq, Aqq ← Aqq + t · Apq, A[p, q] = A[q, p] = 0.
   - Пересчитываем остальные строки/столбцы p и q.
   - Обновляем матрицу собственных векторов V.
   - S ← S − Apq².
5. Возвращаем diag(A_curr) и V.

> **Важно:** при обновлении диагонали используются исходные значения App, Aqq, Apq, сохранённые до обнуления A[p, q]. Иначе Apq станет нулём и диагональ не изменится.

## Сложность

- Одна итерация: O(n).
- Полная сходимость: O(n²) итераций в худшем случае, на практике — существенно меньше.
- Память: O(n²).
